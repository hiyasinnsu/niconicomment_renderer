# ニコニコメント合成 (niconicomment_renderer)

ブラウザ拡張機能「[コメント増量](https://chromewebstore.google.com/detail/eeanibgekifamcnnieknbhjcoocnpipe)」で保存したニコニコ動画のコメントを、手元の動画に重ねてプレビューし、MP4 として書き出す Web アプリです。

**使う:** https://hiyasinnsu.github.io/niconicomment_renderer/

動画とコメントはブラウザの中だけで処理され、どこにも送信されません。

## 使い方

1. ニコニコ動画の視聴ページでコメント増量を使ってコメントを読み込み、「JSONをダウンロード」で保存します（「XMLでダウンロード」で保存したXMLも使えます）。
2. このアプリで「動画ファイル」と「コメントファイル」を選びます（ドラッグ＆ドロップでも可。コメントファイルは複数まとめて読み込めます）。
3. プレビューを見ながら設定を調整します。設定はブラウザに保存されます。
4. 「書き出す」で、コメント入りの MP4 を保存します。

動画とコメントの位置がずれている場合は「タイミング補正」で合わせてください。

## コメントの表示

コメントの配置・速度・文字サイズ・行間・縁取り・フォントは、ニコニコ動画の視聴ページが読み込む公式のコメント描画処理を読み取り、同じ規則で描いています。

- 基準の高さ 384px、文字サイズ（big / medium / small）と行間、複数行コメントの縮小、`ender` / `full`、固定コメントの幅合わせ
- 流れるコメントは表示前後 1 秒を含めて画面を横切り、固定コメントは 3 秒（`@秒数` で変更）
- 衝突判定と、画面からあふれたときの位置決め
- 色コマンド（プレミアム色を含む）と `#RRGGBB`、`ue` / `shita`、`defont` / `gothic` / `mincho`、`invisible`、`_live`（半透明）
- 黒い文字は白い縁取り、それ以外は黒い縁取り
- 投稿者コメントは視聴者コメントとは別のレイヤーで最前面
- OS ごとのフォント（Windows は Arial + MS P ゴシック など）

公式との違い:

- 公式は 1 レイヤーにつき 40 件までしか同時に表示せず、あふれると古いコメントから消します。コメント増量で大量に読み込むとほとんど表示されなくなるため、既定では上限なしにしています（「同時に表示するコメント数の上限」で 40 に戻せます）。
- 公式は再生中に少しずつ配置を決めるため、シークすると並びが変わることがあります。このアプリは先頭から再生したときの配置を最初に計算するので、プレビューと書き出しで同じ結果になります。
- 動画より後ろの時刻のコメントは表示しません（長さの違う動画やタイミング補正のため）。
- ニコスクリプト（「＠ボタン」など）は実行しません。

## 設定

コメント増量と同じ設定:

| 設定 | 内容 |
| --- | --- |
| コメントの大きさ | 文字の大きさの倍率 |
| 縁取りの濃さ | 縁取りの不透明度（公式は 0.4） |
| 不透明度 | コメント全体の不透明度 |
| フレームレート | プレビューの描画と書き出しのフレームレート |
| フォント | 標準（公式と同じ）/ メイリオ / 任意のフォント |
| コメントアートが崩れないようにする | コメントアートを投稿したユーザーのコメントを別の衝突判定にして、他のコメントに押されて崩れないようにする |
| NG共有レベル・ニコられ数・プレミアム会員・かんたんコメント・NGワード・NGコマンド | コメントの絞り込み |

このアプリ独自の設定: 縁取りの太さ、コメントの描画範囲（16:9 / 動画の比率）、同時表示数の上限、タイミング補正、投稿者コメントの表示、書き出しの解像度・ビットレート・方式・音声。

## 書き出し

- **高速（既定）**: WebCodecs で H.264 に符号化して MP4 にします。MP4 の動画は直接復号するので、動画の長さよりかなり短い時間で終わります。AAC 音声はそのままコピーします。MP4 以外（WebM など）は 1 フレームずつ読み込むので時間がかかります。
- **再生しながら録画**: WebCodecs が使えないブラウザ向けです。動画と同じ時間がかかります。

Chrome / Edge では保存先を選ぶ画面が出て、ファイルへ直接書き込みます（大きな動画でもメモリを圧迫しません）。書き出しには Chrome / Edge の最新版を推奨します。

## 対応するコメントファイル

- コメント増量の JSON（`[{ fork, comments: [...] }, ...]`）
- ニコニコの API 形式（`{ data: { threads: [...] } }`）、コメントだけの配列
- 旧形式の JSON（`[{ chat: {...} }, ...]`）と XML（`<packet><chat .../></packet>`）

## 開発

ビルドは不要です。静的ファイルをそのまま配信します。

```
index.html      画面
style.css
js/app.js       画面の操作・プレビュー
js/renderer.js  コメントの配置と描画
js/comments.js  コメントファイルの読み込みと絞り込み
js/exporter.js  動画の書き出し
lib/            同梱ライブラリ
```

ES モジュールを使うので、ローカルで試すときは `file://` ではなく HTTP サーバーで開いてください。
